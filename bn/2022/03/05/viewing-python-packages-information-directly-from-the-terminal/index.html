এটা আমার কেন দরকার?

প্রোগ্রামার হিসেবে টার্মিনাল ব্যবহার আপনি নিশ্চয়ই জানেন। কখনো কখনো শুধু ব্রাউজার খুলতে ইচ্ছা করে না — হয়তো দেখতে চান আপনার প্রিয় Python প্যাকেজের ডাউনলোড কত, বা django-র মতো কোনো নির্দিষ্ট লাইব্রেরিতে কোনো কাজ কীভাবে করে তা দেখতে চান, বা কোনো প্যাকেজ আদৌ আছে কি না আর ইনস্টলের আগে তার বিবরণ দেখতে চান। আমিও এই সমস্যাগুলোর মুখে পড়েছি, তাই টার্মিনালের ভেতর থেকেই PyPI-র সাথে কাজ করার জন্য নিজের একটি লাইব্রেরি বানিয়ে ফেলেছি।

এ থেকে আমি কোনো আয় করি না, করতে চাইও না, এটা পুরোপুরি ব্যবহারকারীদের প্রোডাক্টিভিটির জন্য

দেখতে কেমন?

Information কমান্ডটি দেখতে যেমন লাগে তার একটি উদাহরণ:

আর search কমান্ডের জন্য:

বাকি ১৫+ কমান্ডের স্ক্রিনশট দেখতে অবশ্যই ডকুমেন্টেশনটি দেখুন

এটা কাজ করে কীভাবে?

Information কমান্ডটি প্রথমে PyPI API ব্যবহার করে প্যাকেজের সাধারণ তথ্য আনে। তারপর GitHub API ব্যবহার করে star, fork, size ইত্যাদি তথ্য নেয়। সবশেষে PyPI Stats API থেকে মাস, সপ্তাহ ও দিনপ্রতি ডাউনলোড সংখ্যা আনে। তারপর এসব একসাথে জুড়ে rich রং, প্যানেল, হাইপারলিংক আর আরও অনেক কিছু দিয়ে একটি সুন্দর প্রদর্শনী তৈরি করে! এতে caching লজিকও আছে যাতে দীর্ঘ কোডিং সেশনে ব্যবহার আরও মসৃণ থাকে!

ইনস্টল করব কীভাবে?

শুধু এটুকু চালিয়েই ইনস্টল করতে পারবেন

তারপর pypi -h কমান্ড দিয়ে পরখ করে দেখতে পারেন। আরও তথ্যের জন্য ডকুমেন্টেশনের ইনস্টলেশন পেজ দেখুন

আর প্যাকেজ info ফিচারটি পরখ করতে চালান:

Django এখানে শুধু উদাহরণ, PyPI-র যেকোনো প্যাকেজের তথ্য দেখতে পারবেন
