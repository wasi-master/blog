প্রোগ্রামিং জিনিসটা তো অনেক দিন ধরেই আছে। মজার তথ্য: প্রথম কম্পিউটার প্রোগ্রামিং ভাষা তৈরি হয়েছিল ১৮৮৩ সালে, অ্যাডা লাভলেস ও চার্লস ব্যাবেজের হাতে। কিন্তু আজকাল আমরা যে জনপ্রিয় ভাষাগুলো দেখি সেগুলো তার তুলনায় অনেক সাম্প্রতিক হলেও তবুও বেশ পুরনো — প্রোগ্রামিং ভাষা C প্রথম আসে ১৯৭২ সালে, মানে ৫০ বছর আগে। এখানে আমি আমাদের চেনা-পরিচিত ও প্রিয় ভাষাগুলোর নতুন প্রতিরূপগুলোর কথা বলব।

## Java

**নতুন বিকল্প**: Kotlin

যদি এমন কোনো পরিবেশে কাজ না করেন যেখানে চাকরির জন্যই Java শিখতে *হবে*, তাহলে বদলে Kotlin ব্যবহার করা উচিত। ভাষাটি ২০১১ সালে JetBrains তৈরি করে। ২০১৯ সালে Google Kotlin-কে Android ডেভেলপমেন্টের জন্য পছন্দের (preferred) ভাষা ঘোষণা করে।

Java অবশ্য শিগগিরই কোথাও যাচ্ছে না। Kotlin-এর তুলনায় Java বেশি দিন ধরে আছে বলে এর সাপোর্ট ও ডকুমেন্টেশনও বেশি। কিন্তু ইন্ডাস্ট্রি দ্রুতই Android ডেভেলপমেন্টের জন্য Kotlin-এ চলে যাচ্ছে, আপনারও Kotlin ব্যবহার করা উচিত।

## C/C++

**নতুন বিকল্প**: Rust

C++-এ memory safety সামলানোর দায়িত্ব ডেভেলপারের, অন্যদিকে Rust-এ আছে স্থায়ী safety সীমা যা `unsafe` কীওয়ার্ড দিয়ে তুলে নেওয়া যায়। Stack Overflow-এর ২০১৬ ও ২০১৭ সালের ডেভেলপার সার্ভের "The Most Loved" ক্যাটাগরিতে এটি শীর্ষস্থান পেয়েছে। এটি C++-এর সাথে বেশ মিল রাখে এবং এর syntax শেখাও সহজ।

## JavaScript

**নতুন বিকল্প**: TypeScript

TypeScript বনাম JavaScript তুলনা করলে — JavaScript হলো ওয়েব ডিজাইনের জন্য হালকা, interpreted, dynamic একটি ভাষা। HTML ওয়েব পেজ সমৃদ্ধ করতে ওয়েব অ্যাপ ডেভেলপমেন্টে এটি ব্যবহৃত হয়। অন্যদিকে TypeScript কাজ করে JavaScript-এর superset হিসেবে। অর্থাৎ TypeScript মানে JavaScript + আরও কিছু বৈশিষ্ট্য।

উল্লেখযোগ্য কিছু ফিচার: Static Typing, উন্নত IDE সাপোর্ট, Type Inference, Interoperability, Strict Null Examination

## Objective-C (iOS-এর জন্য)

**নতুন বিকল্প**: Swift

Apple-এর ভাষ্য অনুযায়ী Swift Objective-C-র চেয়ে প্রায় ২.৬ গুণ দ্রুত। Swift দিয়ে কোড লেখার গতিও Objective-C-র চেয়ে উল্লেখযোগ্যভাবে বেশি। Swift-এর syntax অনেক সরল ও সরাসরি।
